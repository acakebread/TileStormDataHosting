TileStorm Content Authoring Guide

This is a short placeholder guide for map authors and submitters. It is intentionally not exhaustive.

Authoring

  • Build and test the map in TileStorm.
  • Keep the final published version clean and readable.
  • The map package is exported separately from the thumbnail image.

Publishing

  • Open the shared map panel in a build that has publish access.
  • Press Publish Current.
  • The app uploads the map package and the thumbnail as separate files using the same hash.

Downloads

  • Use the portal landing page to browse maps.
  • Open the map file link to download the package.
  • Use the thumbnail only as a preview asset.

Deletion

  • Deleting a map should remove both the package and the matching thumbnail.
  • The shared hash is what keeps those two files paired.
