How to use shared maps

Community maps can be opened from this page or from inside TileStorm Evolution.

  • Click Open in TileStorm on any map to launch the game with that map selected.
  • Use Download if you want to save the map package manually.
  • Open the authoring guide if you want to create, publish, or update your own shared maps.
