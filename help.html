TileStorm Help

Community maps can be opened from the shared map list or from inside TileStorm Evolution.

Shared Maps

  • Click a map thumbnail to launch TileStorm Evolution with that map selected.
  • Click Launch in the footer, or eggbot in the title bar, to start the live WebGL build.
  • Use the save icon or JSON filename below a level name to save the map package manually.
  • Inside TileStorm Evolution, use Options > Community to browse and import shared maps in-game.

Publishing

Use the authoring guide when you want to create, publish, or update your own shared maps.
