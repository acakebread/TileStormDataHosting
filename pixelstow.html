PixelStow

Encode text into an image, or read it back. TileStorm Evolution uses the same idea to store level data in the media cards players share. The signal is made to survive social-media recompression. A high-resolution photo looks ostensibly the same; on a small image the change can be visible. The picture is processed in this browser and is not uploaded.

Choose a PNG or JPEG. A fingerprint is saved as a new PNG or JPEG, so the original file stays as it is.

Encoded Source

Scroll over the picture to zoom. Hold the right mouse button to pan.

Drag the divider with the left button. The encoded image is on the left and the recovered source is on the right.

Leave this blank for a public message. A password locks the text. It is not stored in the image.
